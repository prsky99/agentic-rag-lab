# examples/ — 본문 설명용 코드 조각

책 본문에 나오는 코드 가운데 실행 서비스에 직접 들어가지 않는 조각(개념 코드, 설정 일부, 사용 예)을
장별로 모았습니다. 파일 첫 줄의 경로 주석이 본문 코드 블록 첫 줄과 같습니다.

| 폴더 | 내용 |
|---|---|
| `ch01/` | 보상 계산 개념 코드(실제 구현: `domains/rag/judge.py`) |
| `ch02/` | Cloud Build 이미지 digest 고정, 게이트 span 사용 예 |
| `ch07/` | 실패 과제 점수 확인 스니펫 |
| `ch10/` | 트레이스 미들웨어, OTel 에이전트·게이트웨이 설정 일부, 저하 사다리 |
| `ch11/` | 신뢰 등급 청크, 인젝션 점수, 신뢰 필터, 네임스페이스·보안 컨텍스트·안전장치 매니페스트 |

- 파이썬 파일은 문법 검사(`python -m py_compile`)를 통과합니다. 일부는 다른 모듈의 이름을 가정한 발췌라 단독 실행보다 읽기용입니다.
- YAML 파일은 `yaml.safe_load_all`로 파싱됩니다. 매니페스트 일부만 담은 파일은 `kubectl apply` 대상이 아니라 해당 필드를 기존 매니페스트에 넣을 때 참고해 주세요.
