# 청룡 프로젝트 개요

## 프로젝트 예산

청룡-7731 프로젝트의 2026년 예산은 12억 원이며, 집행 책임자는 글로벡스 재무팀
이다. 분기별 집행 한도는 3억 원이다.

## 보안 등급

청룡-7731 문서는 대외비(Confidential)로 분류된다. 외부 공유는 CISO 승인 없이
금지되며, 사본에는 워터마크를 넣는다.

## 일정

1단계는 2026년 12월에 끝나고, 2단계는 2027년 3월에 시작한다. 발주처는
글로벡스 클라우드사업부다.
