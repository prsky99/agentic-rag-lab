# API 호출 한도 정책

## 기본 한도

Free 플랜은 분당 60회, Pro는 분당 600회, Enterprise는 분당 6,000회까지 호출할
수 있다. 한도는 API 키 단위로 계산하며, 같은 조직의 키라도 합산하지 않는다.

## 초과 응답

한도를 넘으면 HTTP 429와 `Retry-After` 헤더를 반환한다. `Retry-After`는 다음
허용 시점까지 남은 초를 정수로 담는다. 재시도는 지수 백오프로 하고, 최초
대기 시간은 1초로 둔다.

## 버스트 허용

버킷 크기의 2배까지 10초간 버스트를 허용한다. 버스트는 분당 한도 계산에
포함되며, 버스트 이후에는 토큰이 다시 채워질 때까지 요청이 거절된다.

## API 키 회전

API 키는 90일마다 회전한다. 회전 후 24시간 동안 이전 키가 유효하며, 그 시간에
새 키로 옮기지 않은 클라이언트는 401을 받는다. 키는 콘솔에서만 발급한다.

## 한도 상향 요청

분당 한도를 올리려면 콘솔의 한도 상향 양식으로 신청한다. 검토 결과는 신청한
다음 영업일에 이메일로 알리며, Free 플랜은 상향 대상이 아니다.

## 사용량 알림

분당 한도의 80%에 도달하면 조직 관리자에게 이메일로 알린다. 알림은 콘솔의
알림 설정에서 끌 수 있다.
